Extrator de Frame para Base64

Carregue um vídeo ou cole um link direto para extrair qualquer frame em formato Base64.

Aviso de CORS: Para links externos, o servidor de origem precisa permitir o acesso CORS (ex: arquivos diretos `.mp4` hospedados publicamente). Caso encontre erros de bloqueio, selecione o arquivo de vídeo diretamente do seu computador.
